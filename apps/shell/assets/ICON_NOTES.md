## Icon files

- `icon.svg` — source of truth (K10 three-chevron placeholder). Replace with brand master when available.
- `icon.png` — 1024×1024 rasterized from the SVG. Generated by ImageMagick.
- `icon.icns` — **NOT generated in the sandbox**. macOS needs a multi-resolution `.icns` file. Run this on your Mac:

  ```bash
  # From the assets/ dir:
  mkdir -p icon.iconset
  for sz in 16 32 64 128 256 512 1024; do
    sips -z "$sz" "$sz" icon.png --out "icon.iconset/icon_${sz}x${sz}.png"
    sips -z $((sz*2)) $((sz*2)) icon.png --out "icon.iconset/icon_${sz}x${sz}@2x.png"
  done
  iconutil -c icns icon.iconset -o icon.icns
  rm -rf icon.iconset
  ```

  Then reference `assets/icon.icns` in `electron-builder`'s `mac.icon` field.
